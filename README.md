# 📋 排班分配器 — Workday Allocation

一个纯前端的排班工具，支持自定义岗位、人员数据库、随机排班生成、配置导入导出。

**在线使用:** https://kaeyounglian.github.io/workday_allocation/

---

## 功能总览

### 🗓 排班表

根据岗位设置和人员数据库，随机生成一周（周一至周日）的排班。

- 每天按岗位分组显示分配的人员
- 岗位显示格式：`岗位名 (已分配人数/最低需要人数)`
- 如果某天某岗人数不足最低要求，标红警告
- 点击 **随机生成排班** 重新生成

### 👥 人员管理

管理所有工作人员的信息。

**添加人员:**
- 填写姓名
- 勾选可担任的岗位（至少选一个）
- 勾选休息日（可选，多选）

**编辑/删除:** 每个人员卡片有编辑和删除按钮

**排班规则:**
- 每人每天只分配一个岗位
- 休息日不会被排班
- 需求越大的岗位优先选人

### ⚙ 岗位设置

默认 4 个岗位 A、B、C、D，可分别修改：

- **岗位名称** — 自命名（例如：前台、客服、保洁、安保）
- **每日最少人数** — 每天该岗位最少需要多少人

### 📦 导入导出

#### 导出
- **📋 复制配置** — 复制 JSON 到剪贴板，可粘贴到其他地方保存
- **📥 下载配置** — 下载为 `.json` 文件

#### 导入
- **粘贴导入** — 把 JSON 文本粘贴到文本框，点击"从粘贴导入"
- **文件导入** — 选择 `.json` 文件上传

> 配置包含岗位名称、最低人数、所有人员信息及休息日。导出的 JSON 可在任意浏览器导入恢复。

## 数据存储

- 所有配置自动保存到浏览器的 **localStorage**
- 刷新、关闭页面不会丢失
- 清除浏览器缓存会丢失数据，建议定期导出备份

### 排班算法

```
每天（周一→周日）：
  按需求从高到低排序所有岗位
  对每个岗位：
    筛选可用人员（当天没休息 + 能做此岗 + 还没被分配）
    随机打乱 → 取前 N 人（N = 该岗最低人数）
    记录已分配人员（每人每天只分配一次）
```
